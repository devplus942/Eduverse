# Project overview

**EduVerse** was a B.Sc. Software Engineering final-year project at Al-Qalam University Katsina (AUK), 2025: a web learning platform combining course delivery, assessment, collaboration and AI assistance for lecturers, students and administrators.

**Problem (from the thesis):** limited interaction, feedback and personalisation in existing e-learning use, and heavy marking workload for lecturers.

**Aim:** a web platform where lecturers publish content and assessments, students learn and collaborate, and AI tools assist with tutoring, feedback and analytics.

**This repository** is a reconstruction of that system written from the thesis documentation after the original source was lost. It is not the original code. Where the thesis was inconsistent or silent, decisions are recorded in [REQUIREMENTS.md](REQUIREMENTS.md). Implementation status and verification are recorded honestly in [TESTING.md](TESTING.md) and [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md).
