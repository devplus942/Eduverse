# User guide

**Administrator:** log in with the account created by `seed_admin.php`. *Users* creates lecturers, students or admins and enables/disables accounts. *Analytics* shows platform totals and links to each course's analytics.

**Lecturer:** on the dashboard create a course. Open it to add lessons (optional file), assignments (deadline notifies students), and live classes (Jitsi link). Open a lesson to add multiple-choice questions. Open an assignment's *Submissions* to run the plagiarism check, request advisory AI feedback and enter the final grade. *Student analytics* lists quiz averages and exports CSV.

**Student:** register, browse *Courses* and enrol. Open lessons, download files, take quizzes (instant score and answers), submit assignments before the deadline (a typed answer is needed for plagiarism and AI feedback), join classes, post in the forum and chat, and ask the *AI tutor*. If the page says MOCK, no real AI is connected.

**Everyone:** use A-/A+ to change text size and *Theme* for dark mode.
